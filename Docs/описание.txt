================================================================================
ЗАВИСИМЫЕ ПАРАМЕТРЫ (СВЯЗАННЫЕ)
================================================================================

Основная зависимость: d >= H / 12

Описание: Диаметр ножки (d) должен быть достаточным для обеспечения устойчивости
конструкции при заданной высоте табуретки (H). Чем выше табуретка, тем толще
должны быть ножки, чтобы выдерживать нагрузку и не сломаться.

Коэффициент 12 взят из эмпирического соотношения для деревянных конструкций,
где минимальный диаметр ножки составляет примерно 1/12 от высоты табуретки.

Примеры:
- При H = 400 мм: минимальный d = 400/12 = 33.3 мм → d >= 33.3 мм
- При H = 450 мм: минимальный d = 450/12 = 37.5 мм → d >= 37.5 мм
- При H = 500 мм: минимальный d = 500/12 = 41.7 мм → d >= 41.7 мм

Механизм валидации:
1. При изменении H пересчитывается минимально допустимое значение d.
2. Если текущее d меньше минимального — выдается ошибка с подсказкой.
3. При изменении d проверяется, что d >= H/12.
4. Поля с ошибкой подсвечиваются, кнопка "Построить" блокируется.


================================================================================
ВЫЧИСЛЯЕМЫЕ ЗНАЧЕНИЯ
================================================================================

1. Длина ножки (L_leg) = H - t
   - Ножка не включает толщину сиденья (t).
   - Пример: H = 450, t = 30 → L_leg = 420 мм

2. Отступ ножки от края сиденья offset = W / 10
   - Используется для пропорционального размещения ножек.
   - Пример: W = 400 → offset = 40 мм

3. Шаг массива (Step) = W - 2 × offset = W - 2 × (W/10) = W × 0.8
   - Расстояние между центрами соседних ножек.
   - Пример: W = 400 → Step = 400 - 2×40 = 320 мм
   - Пример: W = 350 → Step = 350 - 2×35 = 280 мм
   - Пример: W = 450 → Step = 450 - 2×45 = 360 мм
